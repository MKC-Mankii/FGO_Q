# FGO 从者硬币、追加技能与等级上限速查表

> 基于 FGO 九周年硬币系统改版后规则整理（追加技能共 5 个，15 绊总计可获得 420 枚羁绊硬币）。

---

## 一、 基础规则一览

| 项目 | 数值 / 规则 | 说明 |
| :--- | :--- | :--- |
| **追加技能总数** | 5 个 | 九周年由 3 个扩充至 5 个 |
| **解锁追加技能** | **120 枚硬币 / 个** | 5 个全开共需 **600 枚**硬币 |
| **追加技能升级** | 最高 **10 级** | 解锁后初始 1 级，升级只消耗素材、QP 与传承结晶，**不再消耗硬币** |
| **圣杯转临 (100→120级)** | **30 枚硬币 / 2 级** | 共 10 次突破，升满 120 级共需 **300 枚**硬币（100 级及以下不耗硬币） |
| **完全体总需求** | **900 枚硬币** | 120 级（300 枚）+ 5 个追加技能全开（600 枚） |
